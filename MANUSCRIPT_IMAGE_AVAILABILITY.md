# Manuscript Image Availability

The public reproducibility repository does not redistribute the source
palm-leaf manuscript images unless redistribution permission has been
independently verified.

The manuscript images used in the controlled experiments are therefore
not included in this release by default.

Where legally and ethically permissible, provenance information and
instructions for obtaining the corresponding source material will be
provided separately.

Annotations, derived evaluation data, scripts, hashes, and numerical
results included in this repository do not imply redistribution rights
for the underlying manuscript images.

Users wishing to reproduce image-based experiments must obtain the
source images from the identified source repository or rights holder
under the applicable access and reuse conditions.
